MAXSM Ratings mod: исправление загрузки качества, 18.11.2026

Файл: maxsm_ratings_fixed.js. Исходник сохранён отдельно как original.js.

Что исправлено:
- Вместо ошибочных Lampa.Storage.get('jacred.xyz') и get('') читаются
  реальные настройки парсера jackett_url / jackett_key.
- В меню «Рейтинг и качество» добавлены отдельные поля адреса JacRed и API-ключа.
  Если отдельный адрес пуст, используются настройки парсера Lampa.
  Если указан отдельный адрес, ключ от другого парсера автоматически не берётся.
- Прямой запрос идёт первым. Удалены HTTP-адреса CORS-прокси.
  Запросы с ключом не передаются публичным прокси.
- Ожидание включает чтение тела ответа; поздние ответы игнорируются.
  Общий предел ожидания качества - 25 секунд; после ошибки метка скрывается.
- Не требуется AbortController (его нет в некоторых старых TV-браузерах).
- Качество читается как число, строка или из названия релиза.
  TS/HDTS/CAM не выдаются за FHD/4K только из-за разрешения файла.
- Одинаковые запросы списка и полной карточки объединяются.

Как использовать:
1. Заменить именно присланную старую версию плагина новой.
   Не запускать старую и новую версии одновременно.
2. Проверить адрес в настройках парсера Lampa. Нужен доступный JacRed,
   совместимый с /api/v1.0/torrents. Обычный Jackett/Prowlarr - другой API.
3. При необходимости в «Рейтинг и качество» заполнить поля
   «JacRed: адрес для качества» и «JacRed: API-ключ для качества».
   Указывать полный URL. Для локального HTTP явно писать http://.
4. Перезапустить Lampa. Старые кешированные метки качества могут храниться сутки.
   При необходимости кнопка очистки кеша в разделе плагина очистит также рейтинги.

Ограничения:
- Исходный jacred.xyz в проверке с сервера: HTTP обрывает соединение,
  HTTPS не проходит проверку сертификата. Старые публичные прокси тоже ненадёжны.
  Это наблюдение из одной сети, не доказательство недоступности для всех.
- Исправление клиентского кода не восстанавливает внешний сервер JacRed.
  Без доступного источника качество не появится, но вечной загрузки не будет.
- Изменены общий сетевой помощник (он используется также XML-рейтингом KP),
  получение качества и поля настроек; сами алгоритмы рейтингов оставлены.
- Проверено: синтаксис JS, 12 сценариев сети/таймаутов/качеств,
  запуск всего плагина с имитацией API Lampa и настоящий HTTP-запрос
  к тестовому JacRed-совместимому серверу. На устройстве пользователя
  и с его действительным парсером пока не проверено.
- Исходные пользовательские настройки и ключи рейтингов сохранены.
  Не публиковать файл без проверки того, какие API-ключи он содержит.
